# 📚 Recursos y Guías Generales

**The Book of Secret Knowledge**
📖 Una colección masiva de manuales, hojas de trucos (*cheat sheets*) y herramientas para administradores de sistemas y profesionales de seguridad.

**Awesome-Hacking**
🛠️ Una lista curada de *frameworks*, herramientas y recursos de aprendizaje increíbles, ideal para explorar diferentes nichos.

**The Art of Hacking**
🎯 Ofrece una gran cantidad de referencias, scripts y herramientas para diversas metodologías de ataque y defensa.

---

# 🛠️ Herramientas de Pentesting y Análisis

**Metasploit Framework**
⚔️ La herramienta estándar en la industria para el desarrollo y ejecución de *exploits* contra máquinas remotas.

**PayloadAllTheThings**
💣 Un repositorio indispensable que contiene una guía completa de *payloads* para saltarse filtros y atacar aplicaciones web.

**sqlmap**
🔍 La herramienta definitiva para automatizar la detección y explotación de vulnerabilidades de inyección SQL.

---

# 🛡️ Ingeniería Inversa y Análisis de Código

**Ghidra**
🔧 Desarrollada por la NSA, es una *suite* de herramientas de ingeniería inversa de software de código abierto muy potente.

**radare2**
🖥️ Un *framework* completo para ingeniería inversa y análisis de binarios que se maneja principalmente mediante línea de comandos.

**Nuclei**
🌐 Un escáner de vulnerabilidades basado en plantillas que permite enviar peticiones a través de múltiples protocolos.

---

# 🔒 Seguridad y Privacidad

**Hashcat**
🔐 Conocido como el recuperador de contraseñas más rápido del mundo, soporta cientos de algoritmos de *hashing*.

**HashiCorp Vault**
🔑 Una herramienta esencial para gestionar secretos (como llaves de API o contraseñas) de forma segura en entornos de desarrollo.
